# Data Folder

This folder is intended to hold the raw data files used in the churn analysis:

- `customer_data.csv` - Raw customer churn data (add your file here)
- `prod_data.csv` - Raw product data (add your file here)

> Note: CSV data files should be uploaded directly via the GitHub web interface (Add file > Upload files) or via git push, since they contain binary/tabular data that cannot be generated automatically.
